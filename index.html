Cách dùng

  1. Mở app TikTok / Instagram / Facebook, chọn video hoặc bài đăng cần tải.
  2. Bấm "Chia sẻ" → "Sao chép liên kết".
  3. Quay lại trang này, dán link vào ô trên và bấm Tải về.
  4. Bấm nút Tải file để lưu video / ảnh về máy.

Lưu ý: bài đăng riêng tư hoặc tài khoản private sẽ không tải được.

Tải video 16:9

Cách dùng

  1. Quay clip CS2 ở chế độ 4:3 stretched như thường (thường record ra 1440×1080).
  2. Mở tab này, kéo file video vào ô trên.
  3. Lần đầu sẽ tải ~30MB ffmpeg.wasm, các lần sau dùng cache nên rất nhanh.
  4. Đợi convert (chậm hơn ffmpeg native vì chạy WebAssembly), rồi bấm Tải video 16:9.

Output: 1920×1080 H.264 + AAC. File chỉ tồn tại trong RAM trình duyệt — không upload đi đâu.

Cách dùng

  1. Chọn Local để xử lý riêng tư hoặc OpenRouter để dùng AI Enhance.
